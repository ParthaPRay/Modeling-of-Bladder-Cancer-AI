# Modeling of Bladder Cancer Recurrence Using Survival AI

This repository provides a reproducible Python-based workflow for modeling bladder cancer recurrence using open recurrent-event data. The study combines conventional survival analysis, recurrent-event modeling, count regression, machine-learning survival prediction, calibration analysis, decision-curve analysis, and explainability.

The main notebook is:

```text
Bladder_Cancer_Recurrence_Survival_AI.ipynb
````

The workflow was developed and tested in Google Colab and is intended for transparent survival-model benchmarking rather than immediate clinical deployment.

## Study Aim

The goal of this repository is to demonstrate how open bladder cancer recurrence data can be analyzed using a reproducible Python pipeline. The workflow supports:

* time-to-first-recurrence modeling;
* recurrent-event modeling;
* recurrence-burden analysis;
* conventional survival statistics;
* machine-learning survival prediction;
* calibration and decision-curve analysis;
* explainability using permutation importance;
* export of publication-ready figures and copyable result tables.

The analysis is intended as a methodological and benchmarking framework. It should not be interpreted as a clinically validated prediction tool.

---

## Dataset

The notebook uses the Kaggle bladder cancer recurrence dataset. During execution, the notebook searches and downloads the dataset through the Kaggle API.

Expected dataset files:

```text

```

The notebook processes these files for complementary purposes:

* `bladder1.csv` is used for full patient-level first-recurrence and recurrence-burden analysis.
* `bladder2.csv` is used for Anderson–Gill start–stop recurrent-event modeling.
* `bladder.csv` is inspected as an additional recurrence-format dataset.

## Analytical Workflow

### Data Preprocessing

The notebook standardizes column names, harmonizes treatment labels, and defines recurrence events. For recurrence analysis, recurrence is treated as the relevant event, while non-recurrence statuses are treated as censored for first-recurrence modeling.

A patient-level first-recurrence dataset is created by sorting each patient’s records by follow-up time and selecting the first recurrence event where present. Patients without recurrence are censored at their last observed follow-up time.

---

## Conventional Survival Analysis

The notebook performs:

* Kaplan–Meier recurrence-free survival analysis by treatment group;
* extraction of recurrence-free survival probabilities at selected time points;
* logrank and weighted logrank tests;
* restricted mean recurrence-free survival time;
* Cox proportional hazards modeling;
* hazard-ratio forest plotting;
* proportional-hazards diagnostics using scaled Schoenfeld residuals;
* penalized Cox model selection using cross-validation;
* parametric survival model comparison using AIC;
* quantile–quantile diagnostics for parametric model adequacy.

---

## Recurrent-event and Count Modeling

The recurrent-event analysis uses the Anderson–Gill start–stop formulation. The notebook fits a Cox time-varying model using start and stop intervals.

Because robust clustered variance is not available for the implemented `CoxTimeVaryingFitter`, standard model-based intervals are reported cautiously. A methodological note is exported automatically:

```text
anderson_gill_methodological_note.txt
```

The recurrence-burden analysis also fits:

* Poisson regression;
* negative binomial regression;
* log-follow-up offset models.

These models provide complementary count-based assessment of recurrence burden.

---

## Machine-learning Survival Models

The notebook trains and evaluates:

* penalized Cox / CoxPH;
* elastic-net Coxnet;
* Random Survival Forest;
* exploratory DeepSurv-style neural CoxPH.

The machine-learning pipeline includes:

* one-hot encoding of treatment variables;
* standardization of numeric predictors;
* train-test splitting;
* survival model fitting;
* C-index evaluation;
* time-dependent AUC;
* integrated Brier score;
* time-dependent Brier score;
* calibration analysis;
* decision-curve analysis;
* permutation importance;
* model-derived risk grouping.

The Random Survival Forest model is implemented as a scikit-learn pipeline with preprocessing and survival estimation.

---

## DeepSurv-style Neural Survival Modeling

The notebook includes an exploratory neural CoxPH model using `pycox` and `torchtuples`.

Because the dataset is small, the neural model uses:

* a compact multilayer perceptron;
* no batch normalization;
* dropout regularization;
* early stopping.

This model is included as a benchmark only. It should not be interpreted as a clinically validated neural survival model.

## Reproducibility Notes

The notebook sets a fixed random seed for NumPy and PyTorch:

```python
RANDOM_STATE = 42
np.random.seed(RANDOM_STATE)
torch.manual_seed(RANDOM_STATE)
```

All main figures are saved in both PNG and PDF formats. All major result tables are exported as CSV files. Model objects are saved using `joblib` or PyTorch state dictionaries.

## Important Interpretation Note

This repository is intended for reproducible survival-model benchmarking using open bladder cancer recurrence data. The dataset is historical and limited in covariate depth. The models and risk groups generated here should not be used for clinical decision-making without external validation in contemporary bladder cancer cohorts.
